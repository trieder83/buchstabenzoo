# App Store packaging (iOS)

## Goal

Ship Letter Zoo / Buchstabenzoo to the Apple App Store as a free, offline game in the **Kids Category** (Q-390),
built on GitHub Actions without a Mac, the same way as ABC Smash (`../abcshooter`, BUILD_IOS.md there).
Languages and storefronts: English (U.S.), English (U.K.), German; US, GB, DE, AT, CH.

## How ABC Smash does it (reference, explored 2026-10-08)

Custom SwiftUI + WKWebView shell (not Capacitor) that **loads the deployed PWA** (URL injected by an xcodebuild setting);
Xcode project generated from `ios-app/project.yml` (XcodeGen) on the runner; manual signing (Apple Distribution `.p12` +
App Store profile from repository secrets, created from Linux with the App Store Connect API script
`scripts/ios-signing-bootstrap.mjs`); `xcodebuild archive` + `-exportArchive` (ExportOptions.plist, manual) +
`xcrun altool --validate-app/--upload-app` with an API key; `workflow_dispatch` only, runner `macos-26`, newest Xcode 26 selected
explicitly (the iOS 26 SDK is required for uploads); `CFBundleVersion` = `<base>.<run number>`; team `AZFUSL233G`; offline via
`WKAppBoundDomains` + service worker; audio session `.playback` + re-activation after interruptions. Pitfalls noted there:
build number must be integers only; the clip needs `CFBundleIconName`; `.p12` must be exported with `-legacy`; the default Xcode lags
the SDK requirement; Apple allows at most two distribution certificates per team (ABC Smash's is the second: **reuse it**).

## Behaviour

1. **Wrapper = Capacitor 8** (CLAUDE.md), project `web/ios` committed (generated by `cap add ios` on Linux, 0.7 MB), config
   `web/capacitor.config.ts`: `appId` `ch.rcms.letterzoo`, `appName` Letter Zoo, `webDir` `dist`. The game is **bundled**
   (Guideline 4.2): nothing is fetched from the web to start or play; origin `capacitor://localhost` (never change it after release:
   it would reset the saves). `.wasm`: Capacitor's scheme handler may send an unknown MIME type, `wasm-bindgen` then falls back to
   `ArrayBuffer` instantiation (works; verify on a device, PLAT-043 manual).
2. **Native flag.** `VITE_NATIVE=1` (`npm run build:native`) -> `web/src/native.ts`: Google Analytics id forced to `''` (no button, no
   script load, no consent dialog, no GA request) and no web posters. The anonymous first-party counters (PLAT-044..053) still run. The web build is unchanged.
3. **Signing/CI.** `.github/workflows/ios.yml` (manual): web native build, `cap sync ios`, archive Release with manual signing set
   on the App target (profile `Letter Zoo App Store`, team `AZFUSL233G`), export, bundle checks, validate + upload to TestFlight.
   Secrets (names only): `IOS_DIST_CERT_P12`, `IOS_DIST_CERT_PASSWORD`, `IOS_PROVISIONING_PROFILE`, `ASC_KEY_ID`, `ASC_ISSUER_ID`,
   `ASC_KEY_P8`. Version = `web/package.json` version, build number = run number. No `ci.yml` (ABC Smash has none); no Android workflow.
4. **Info.plist.** `ITSAppUsesNonExemptEncryption` false (only Ed25519/SHA signature verification and Apple's system networking:
   exempt), no `NS*UsageDescription`, no background modes, `CFBundleLocalizations` de + en (the product page language list comes
   from the bundle), portrait + landscape (iPad all four), status bar hidden, `arm64` + `metal`, deployment target iOS 15.0
   (WebGL2). Safe areas: `contentInset: never` + the existing `env(safe-area-inset-*)` (PLAT-021).
5. **Audio.** `AVAudioSession` `.playback` + `.mixWithOthers`, re-activated when the app becomes active (Q-395).
6. **Icon and splash.** `tools/make_icons.py` writes the 1024x1024 RGB (no alpha) App Store icon and the cream launch image into
   `web/ios`. The user approves the icon (ART-PIPELINE gate).
7. **Compliance.** Kids Category: no third-party analytics/ads network (5.1.4; first-party anonymous counters without identifiers are allowed), links out only behind the parental gate (1.3), no donation or
   purchase prompt (3.1.1), no names of other platforms (2.3.10). Privacy label: Usage Data > Product Interaction, Analytics, Not Linked to You, no tracking (anonymous counters, PLAT-044..053). Age rating 4+. Details and the
   listing: `store/appstore/README.md`.
8. **Texts.** `store/appstore/{en-US,en-GB,de-DE}/` one file per field within the limits (name 30, subtitle 30, promotional text 170,
   description 4000, keywords 100), `review_notes.txt`. The listing positions the app as a reading game with small in-world posters of
   the developer's other apps, never as advertising (4.2.2).
9. **Screenshots.** `tools/store/make_appstore_screenshots.py` writes exact sizes (iPhone 6.9" 1320x2868, 6.5" 1284x2778, iPad 13"
   2064x2752, both orientations) from `art/marketing/screens`, scaling down only.

## Native posters (user decision 2026-10-08, Q-392)

The posters of the native build advertise only the developer's own iOS apps. Separate signed manifest `boards-native/index.json`
+ `.sig` (images in `boards-native/img/`), emitted by `vite.config.ts` into the app as `boards/` (same path, so the loader is
unchanged and nothing is downloaded). Campaigns (`tools/ads/campaigns-native.template.json`): `mathfighter-ios` slot 1,
`abcsmash-ios` slot 2, `mathfighter-ios-b` slot 3 (the website campaign EduGameGalaxy is dropped; repeating Math Fighter keeps
ADS-002 "every slot on every level"). Links are `https://apps.apple.com/app/id<ID>` with the ID **fixed in the game**
(`KNOWN_CAMPAIGNS` entry gets a `path`), opened only after the existing parental gate. Opening: `window.open(_blank)`; Capacitor's
`WKUIDelegate` hands it to `UIApplication.open`, which launches the App Store app (lowest risk, no plugin; an in-app
`SKStoreProductViewController` needs a custom Swift plugin that cannot be built or tested on Linux: later option).
**Applied 2026-10-08** (ads agent): items 1-4 below are done (`KNOWN_CAMPAIGNS` has the three native ids with a fixed path; `sign.py` mirrors them; `boards-native/index.json` + `.sig` signed with the production key, version 1, valid 365 days, re-sign with each app release; `NATIVE_ADS = true`); tests in `web/src/native.test.ts` (PLAT-038). The native manifest uses only `link` (no `links`, no web / Play link); any other host or path drops the campaign.

1. `web/src/ads.ts`: `KNOWN_CAMPAIGNS` type gets `path?: string`; add `'mathfighter-ios': { slot: 1, host: 'apps.apple.com', path: '/app/id6760628828' }`,
   `'abcsmash-ios': { slot: 2, host: 'apps.apple.com', path: '/app/id6790508038' }`, `'mathfighter-ios-b': { slot: 3, … id6760628828 }`;
   `checkLink`: `known.path ? u.pathname === known.path : (u.pathname === '/' || u.pathname === '')`, canonical result `https://${host}${path ?? '/'}`.
2. `tools/ads/sign.py` `KNOWN`: same three ids with `"apps.apple.com/app/id…"` as the "host" part (its check is `https://{host}`).
3. Sign (key never printed, never in CI): `python3 tools/ads/sign.py --key ~/secrets/zoo-ads.key --template tools/ads/campaigns-native.template.json --ads-dir boards-native --version 1 --valid-days 365`
   (after `valid_until` the posters fall back to placeholders; re-sign with each app release).
4. `web/src/native.ts`: `NATIVE_ADS = true`. Until then the native build shows placeholders only and makes no ad request.

## What Apple allows and what is a review risk (Guidelines read 2026-10-08, developer.apple.com)

Allowed: links out of a Kids Category app **inside a designated area behind a parental gate** (1.3); first-party promotion of own
apps (the 3rd-party-advertising ban of 1.3/5.1.4 concerns third parties); a free app without purchase prompts; anonymous first-party counters (privacy label Product Interaction / Analytics / not linked / no tracking).
Risks: **4.2.2** ("apps shouldn't primarily be marketing materials, advertisements ... or a collection of links": the posters are a
small decoration of a full game; keep them small, never in menus, say so in the review notes); **1.3** ("must not include links out
... or other distractions to kids unless ... behind a parental gate": the gate must be robust: the existing sum + hold + release);
**2.3.10** (no names, icons or imagery of other platforms: the native manifest has no itch.io / Google Play / website campaign; the
poster images must show no store badges: they do not); **2.3.1** (every feature in the review notes: done); **2.3.8 / 5.1.4(b)** (child
wording in metadata is only allowed in the Kids Category: Q-390 is tied to the texts); **3.1.1** (no donation or external purchase link:
none in the game; ABC Smash costs 5.99 USD and Math Fighter has in-app purchases, so the product pages show purchase opportunities
behind the gate, which 1.3 allows); the Math Fighter images show stylised fighters (age-appropriateness, Q-392).
